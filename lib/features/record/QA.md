## 2. 服用記録

- [x] **服用ボタンで記録**: 画面下部の「飲んだ」ボタンをタップすると本日分の錠に服用済みマークが付き、ボタンが「飲んでない」（取り消し）ボタンに切り替わる
- [x] **シート上マーク直接タップで服用/取消**: ピルシート上の本日分でまだ未服用の錠マークを直接タップすると服用記録が付く。全て服用済みの状態でシート上の服用済みマーク、または「飲んでない」ボタンをタップすると直前の服用記録が取り消され「飲んだ」ボタンに戻る
- [x] **未来の錠はタップ無効**: 本日の錠番号より先（未来）の錠マークをタップしても服用記録は付かず、画面表示・ボタン状態は変化しない
- [x] **1日2回服用の記録**: 服用回数 2 回のシートでは「飲んだ」1 回目で本日の錠の残り回数が「1」になりボタンは「飲んだ」のまま、2 回目で服用済みチェックになり「飲んでない」に切り替わる
- [x] **深夜服用の注意ダイアログ**: 0:00〜2:00 の間に服用記録すると「ご注意ください」ダイアログ (本日分として記録され、当日の通知は届かない旨) が表示される。初回は「閉じる」のみ、前回表示から 30 日以上経った 2 回目以降は「二度と表示しない」が追加され、押すと以後表示されない

## 3. ピルシートグループ追加

- [x] **空状態からの追加フローとシートタイプ選択**: ピルシート未作成またはシート終了時はホーム中央に「＋ ピルシートを追加」の空状態枠が表示され、タップすると追加ページに遷移する。シートタイプ（21錠/24錠/28錠等）を選択すると一覧に追加され、追加済みシートのタイプ変更・削除もでき、シートタイプが1件も無い場合は「追加」ボタンが無効になる
- [x] **通し番号（周期表示）の開始番号設定**: 表示モードが周期表示で前回のグループがある場合、追加ページに「服用 n 番からスタート」の開始番号の入力欄と、前回グループの最後の番号「前回のシートの最後：N番」(`sequentialEstimatedEndPillNumber`。入力値には連動しない固定値) が表示され、入力した番号から新しいグループの表示番号が始まる
- [x] **服用回数の設定**: 追加ページの「1日に n 回服用する」に 2 を入力して追加すると、1 日 2 回服用のピルシートグループが作られる。入力欄が空の間は「追加」ボタンが無効になる

## 4. 休薬期間管理

- [x] **休薬開始**: ピルシート設定シートの「休薬を始める」をタップすると確認ダイアログ（服用番号は進まない旨の注意書き付き）が表示され、開始を選ぶと休薬が始まりホーム下部のボタンが操作不可の「休薬中」ボタンに変わる
- [x] **服用済み時は休薬開始不可**: 本日分を服用済みの状態で「休薬を始める」をタップすると、休薬前に本日の服用を取り消すよう案内するエラーダイアログが表示され、休薬は開始されない
- [x] **休薬終了と期間変更**: 休薬中にピルシート設定シートの「服用を再開する」をタップすると休薬が終了し完了のスナックバーが表示されて通常の「飲んだ」ボタンに戻る。終了後は設定シートの休薬期間一覧から対象期間をタップし、日付ピッカー（単日または期間）で開始日・終了日を変更できる。最後に服用した日の翌日 (`availableRestDurationBeginDate`) より後を開始日にするとエラーダイアログで拒否される
