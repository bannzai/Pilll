# before_pill_sheet_group_history QA

一つ前 (前回) のピルシートグループを表示する画面（`BeforePillSheetGroupHistoryPage`）。記録画面ヘッダー右上の履歴アイコンから遷移する。ピルシートと修正履歴の閲覧に加えて、前回のピルシートグループに対する「終了日つきの服用お休み期間」の追加・変更ができる（新しいピルシートグループに切り替わった後でも前回の休薬を記録・修正できるようにするため。継続中の服用お休みはこの画面では作らない）。

## 関連リンク

- 仕様: https://github.com/bannzai/PilllBackend/issues/395
- 関連: https://github.com/bannzai/PilllBackend/issues/389

- [x] **画面到達と初期表示**: 記録画面ヘッダー右上の履歴アイコンをタップすると本画面が開き、AppBar タイトルに「前回のピルシートグループ」、その下に前回グループの開始日〜終了予定日が「yyyy/MM/dd ~ yyyy/MM/dd」形式で表示される。前回グループの状態は、設定タブ →「開発者オプション」→「終了済みの前回ピルシートグループを作成」で作る（現在のグループを過去にずらして 21 番まで服用済みの終了状態にし、今日から始まる新しいグループを作る）

## 4. 服用お休み期間の追加・変更

- [x] **服用お休み期間の追加**: 「服用お休み期間を追加」をタップすると DateRangePicker が開き（先頭シートの開始日〜今日）、開始日〜終了日を選んで保存すると一覧に「服用お休み期間変更 開始日 - 終了日」の行が追加され、スナックバー「服用お休み期間を追加しました」が表示される
- [x] **開始日の上限**: 開始日が「最後に服用した日の翌日」（または最終シートの終了予定日のうち早い方）より後の期間を保存すると、エラーダイアログ「服用お休み開始日は{日付}以前の日付を選択してください」が表示され保存されない
- [ ] **他の服用お休み期間との重なり**: 既存の服用お休み期間と重なる期間を保存すると、エラーダイアログ「他の服用お休み期間と重なる期間は選択できません」が表示され保存されない。終了日が既存の開始日と同じ日、開始日が既存の終了日と同じ日は重ならない扱いで保存できる
  - ⏭️ スキップ: 画面では未実施。判定ロジックは provider_test.dart で境界値を含めて検証済み
- [x] **服用お休み期間の変更**: 既存の「服用お休み期間変更」行をタップすると現在の期間が選択された DateRangePicker が開き、変更して保存すると行の期間が更新され、スナックバー「服用お休み期間を編集」が表示される
- [x] **後続シートと終了予定日への反映**: 追加・変更後、上部の終了予定日が休薬日数分延び、後続のピルシートの開始日が前のシートの終了予定日の翌日に更新される
- [x] **現在のピルシートグループに影響しないこと**: 前回グループで服用お休み期間を追加・変更しても、記録画面の最新グループの開始日・服用番号は変わらない
- [ ] **破棄済みグループでは編集できないこと**: 前回グループが「ピルシートをすべて破棄」で破棄されたものの場合、服用お休み期間の追加・変更の行は表示されない
  - ⏭️ スキップ: 破棄済みグループの状態は用意しなかったため未実施
