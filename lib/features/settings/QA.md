# settings QA

設定画面は項目数が多いため、主要フローを中心にテスト項目を定義する。

確認環境 (2026-10-15〜16 の記録): iPhone 16 Pro シミュレータ (iOS 27.0、ローカル sim-boot、`SIMSLIM_EXCEPT=store,health,icloud,widgets`) の dev ビルド (HEAD を Flutter 3.44.9・Xcode 27.1 でビルド)。トライアル中の確認は 2026-10-15、「トライアル解除」後の無料ユーザーの確認は 2026-10-16 に行った。確認日が 2026-10-04〜08 の項目は、前回 (commit 75c754dd72 を Xcode 26.5 でビルド) の記録のまま。

## 1. アカウント

- [x] **連携状態の表示 (未連携)**: 「アカウント設定」行はApple/Googleいずれも未連携なら「未登録」と表示される
- [ ] **連携状態の表示 (連携済み)**: Apple/Googleのいずれか連携済みなら「アカウント設定」行に「連携済み」と表示される
  - ⏭️ スキップ: Apple/Google 連携が実 OAuth 認証 (Apple Account / Google アカウントの認証情報) を要しシミュレータでは完了できないため未検証
    - 起動条件: ローカル sim-boot。`SIMSLIM_EXCEPT=store,health,icloud` / `SLIM_STATUS=APPLIED` (2026-10-05)、`ALREADY_SLIM` (2026-10-08)
    - デーモン: icloud カテゴリを有効にした状態で、Apple 連携は OS の「Apple Account にサインインしてください」ダイアログまで到達する (「アカウント連携導線」のスクショ。`launchctl list` の出力は取っていない)
    - 試した手順: 連携一覧 → Apple「連携する」→ サインインシート「Appleで登録」→ Apple Account 未サインインのため OS ダイアログで停止。Google「連携する」→ accounts.google.com のログイン画面まで到達、テストアカウントの認証情報が無いため中断
- [x] **アカウント連携導線**: 「アカウント設定」から連携一覧画面に遷移し、未連携のApple/Googleで「連携する」をタップするとサインインシートが表示される。実OAuth認証結果の確認はSimulatorでは制限があるため、シートと OS のダイアログの表示までを確認対象とする
- [ ] **再ログイン導線**: 連携済みの行を長押しすると「認証情報を更新します」の再ログイン確認ダイアログが表示される
  - ⏭️ スキップ: 匿名アカウントのため連携済み行が存在せず、シミュレータで実 OAuth 連携を完了できないため未検証 (起動条件・試した手順は「連携状態の表示 (連携済み)」と同じ)
- [x] **退会**: 連携一覧画面下部の「退会する」をタップすると確認ダイアログが表示される。退会は不可逆操作のため、実際の削除実行はQA専用の使い捨てアカウントでのみ行い、通常は確認ダイアログの表示までに留める

## 4. 通知設定

- [x] **服薬リマインダーのON/OFF**: 「ピルの服用通知」トグルをOFF→ONに切り替えるとSnackBar「服用通知をONにしました」、ON→OFFに切り替えると「服用通知をOFFにしました」が表示される
- [x] **服薬リマインダーのON/OFFによる通知の登録・キャンセル**: トグルをONにするとローカル通知が登録され、OFFにするとキャンセルされる
- [x] **通知時間の変更**: 「通知時間」をタップすると時刻編集画面に遷移し、変更後は設定画面の行に変更後の時刻一覧が反映される
- [x] **プレミアム限定の通知機能導線**: 「マナーモードでも通知設定」はプレミアム/トライアル会員では音量スライダーとテスト通知ボタン付きの設定画面に遷移し、非会員ではプレミアム紹介シートが表示される。「服用通知のカスタマイズ」はプレミアム/トライアル会員では編集画面に遷移する
- [x] **プレミアム限定の通知機能導線 (服用通知のカスタマイズ・トライアル中のアラーム機能)**: 非会員が「服用通知のカスタマイズ」をタップするとプレミアム紹介シートが表示される。トライアル中のユーザーが「アラーム機能」(iOS) のスイッチをタップすると OS のアラーム権限を求め、許可されなければ「アラーム機能の権限が必要です。設定から許可してください。」のスナックバーが表示される
- [x] **無料ユーザーのアラーム機能**: 無料ユーザーが「アラーム機能」(iOS) のスイッチをタップするとプレミアム紹介シートが表示され、スイッチは OFF のままになる (他の Premium 行と同じ)
